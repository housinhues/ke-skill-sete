# superfly-pitch-dashboard

A reusable internal ops dashboard and pitch dashboard skill for Housing Hues event productions.

## What it does
- Tracks artist roster with booking fees, Instagram handles, and follower counts
- Tracks marketing budget line items with totals
- Provides a progress/status tracker for outstanding items
- Summarises total production cost across bookings + marketing
- Hold-to-edit inline editing on any field
- 3D card tilt on hover
- Sponsor name swappable in header for different pitches

## When to use
Trigger this skill when building:
- Internal event ops dashboards for Housing Hues productions
- Sponsor pitch dashboards
- Artist roster + booking fee trackers
- Event production budget overviews

## Design system
- Light background: `#f5f5f2`
- Gold accent: `#c9a800`
- Bebas Neue for display/numbers, Inter for body
- Cards with subtle 3D tilt on hover
- Hold-to-edit: hold button 800ms to unlock inline editing

## Customise per production
1. Replace artist array with correct roster + fees
2. Replace budget array with correct line items
3. Update schedule dates and venue
4. Update sponsor name in header
